Privacy Policy

Dry Run · Last updated October 2026

Dry Run ("the app") is a presentation rehearsal tool built for the Google Cloud AI Builder Cup 2026. This policy explains what data the app accesses and how it is used.

Data We Access

When you sign in with Google, the app may request access to:

  • Google Drive (read-only): to let you import proposal documents from your Drive into a rehearsal session.
  • Google Calendar (read-only): to display your upcoming meetings on the home dashboard so you can link a rehearsal to a specific event.
  • Google Docs (create): to export your post-session coaching report as a new Google Doc in your Drive.

How Data Is Used

  • Proposal text you upload or import is sent to the Google Gemini API solely to generate rehearsal challenges and a coaching report.
  • No proposal text, transcript or personal data is stored on any server. All session state lives in your browser's local storage and is cleared when you delete a session.
  • Google OAuth tokens are stored in your browser's local storage and are never transmitted to any third party.

Third-Party Services

The app uses the following Google Cloud services: Gemini API (AI responses), Firebase Hosting (app delivery) and Firebase Cloud Functions (API backend). All are subject to Google's Privacy Policy.

Data Retention

The app stores no data on external servers. All session history is kept locally in your browser and can be deleted at any time from within the app.
